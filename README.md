# Bestie Portal 🎀

A cute four-page bestie prank website made with HTML, CSS, and JavaScript.

## Pages
1. Welcome page — enter a name and password.
2. Confirmation page — “Do you REALLY wanna open it?”
3. Rage-bait page — click for more silly messages.
4. Cat reveal — displays the original kitten GIF embedded in the HTML.

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and this `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Important password note
The demo password is checked in browser-side JavaScript, so this is only a fun gate—not secure authentication. Anyone who views the source code can discover it.
